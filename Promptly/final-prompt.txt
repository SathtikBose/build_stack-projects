# Promptly - AI Chat Android App

## Project Overview

### App Name
Promptly

### Package Name
com.buildstack.promptly

### Platform
Android

### Tech Stack
- Kotlin
- Jetpack Compose
- Room Database
- Retrofit
- Kotlin Coroutines
- MVVM Architecture
- Navigation Compose
- DataStore Preferences
- Groq API
- Material 3

### Objective

Promptly is a modern AI chat application inspired by ChatGPT with a cyberpunk-inspired futuristic interface. Users can create unlimited chats, interact with AI using the Groq API, store conversations locally using RoomDB, and manage chats without requiring authentication.

The application must be production-ready, scalable, maintainable, and follow clean architecture principles.

# DATABASE SCHEMA

## Chat Table

Table Name:
chat_table

| Field | Type |
|---------|---------|
| chatId | Long |
| title | String |
| createdAt | Long |
| updatedAt | Long |

---

## Message Table

Table Name:
message_table

| Field | Type |
|---------|---------|
| messageId | Long |
| chatId | Long |
| role | String |
| content | String |
| timestamp | Long |

Role Values

- user
- assistant

---

## Relationships

One Chat
→ Many Messages

Foreign Key

message.chatId
references
chat.chatId

# API DESIGN

## Provider

Groq

Base URL

https://api.groq.com/openai/v1/

---

## Endpoint

POST

/chat/completions

---

## Request

{
  "model":"llama-3.3-70b-versatile",
  "messages":[
    {
      "role":"user",
      "content":"Hello"
    }
  ]
}

---

## Response

{
  "choices":[
    {
      "message":{
        "content":"Hello!"
      }
    }
  ]
}

---
