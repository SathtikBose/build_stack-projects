# Core Features

## 1. Splash Screen

Create:

* animated splash screen
* app logo animation
* smooth transition to home screen

---

## 2. Home Screen

Features:

* list all notes
* beautiful glassmorphism note cards
* floating action button at bottom right
* empty state UI
* search bar
* sorting options
* recent notes section
* skeleton loading animation while loading data

Locked notes:

* show lock icon
* do not show note preview content
* show blurred placeholder instead

---

## 3. Create/Edit Note Screen

Features:

* auto save while typing
* create note
* update note
* delete note
* smooth keyboard behavior
* rich text editor toolbar

Formatting support:

* heading
* bold
* italic
* underline
* strikethrough
* bullet points
* checklist
* quote block
* code block
* text colors
* alignment options

Use modern compose rich text handling.

---

## 4. Note Security

Allow users to:

* lock notes using PIN
* unlock using biometric authentication if available
* fallback to PIN if biometric unavailable

Security requirements:

* encrypted storage for PIN
* biometric prompt integration
* protected note opening
* protected deletion for locked notes

If locked:

* note preview hidden
* content inaccessible without authentication

---

## 5. Note Selection

Interaction:

* click note → open note
* long press for 3 seconds → selection mode
* multi-select support
* delete selected notes

If deleting locked note:

* require biometric or PIN verification first

---

## 6. Animations

Implement:

* shared transitions
* fade animations
* scale animations
* FAB animations
* shimmer skeleton loading
* smooth screen transitions
* swipe animations

Animations should feel smooth and premium.
