# SkyCast - Production Ready Weather Application

## Project Overview

**App Name:** SkyCast  
**Package Name:** com.buildstack.skycast  
**Platform:** Android  
**Language:** Kotlin  
**UI Framework:** Jetpack Compose  
**Architecture:** MVVM + Clean Architecture  
**Networking:** Retrofit + OkHttp  
**Dependency Injection:** Hilt  
**Database:** Room Database  
**Image Loading:** Coil  
**Navigation:** Navigation Compose  
**API Provider:** OpenWeather API  
**Minimum SDK:** 26 (Android 8.0)  
**Target SDK:** Latest Stable  
**Build System:** Gradle Kotlin DSL

---

# PRODUCT REQUIREMENTS DOCUMENT (PRD)

## Vision

SkyCast is a premium weather intelligence application that delivers real-time weather conditions, forecasts, and air quality insights through a highly polished, modern dark-themed experience.

Unlike typical weather demo applications, SkyCast focuses on:

- Premium visual design
- Smooth animations
- Rich weather insights
- Air quality intelligence
- Fast performance
- Offline support
- Global location support
